2 · Translate anywhere

Export the segments as TXT, Word, XLIFF, CSV or JSON. Translate them in DeepL, Google Translate, a chatbot, a CAT tool or with a human translator, then import the result. You can also edit translations here.

The original text is removed and the translation is written into the same place. Images, vector graphics and the rest of the page are not touched.

Rebuild the PDF

Only segments that have a translation are replaced. All other text, images and drawings are kept.

Choose a .ttf/.otf font that covers the target language.

Built-in fonts cover Latin, Greek, Cyrillic, Chinese, Japanese and Korean. For other alphabets, upload a font that supports them. Right-to-left and complex scripts (Arabic, Hebrew, Indic, Thai) are not shaped correctly.

Help

  1. Extract: open a PDF. Each paragraph, label and table cell becomes a numbered segment; click a box on the page to jump to it.
  2. Translate: type in the boxes, or use an AI or translation tool with the prompt below and paste its answer into Import.
  3. Rebuild: Build PDF writes every translation into the PDF. To fix one segment afterwards, edit it and press ⟳ update PDF on its card (or Ctrl+S). Only that page is redone.

Shortcuts in a translation box: Ctrl+Enter next segment · Alt+↑/↓ previous/next · Ctrl+S update this segment in the PDF.
